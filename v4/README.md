# Portafolio v4

Portfolio (proyecto de Lovable, podado a solo la web: sin TanStack Start,
sin SSR/Nitro, sin Supabase server, sin tests ni scaffolding de Lovable).
Vite + React 19 + Tailwind 4 + Three.js, con el copy de Julia Prat.

## Preview deployment

Vive dentro del repo Portafolio-v2, en la carpeta `v4/`. El workflow de
GitHub Pages del repo lo construye y lo publica en
https://japm01.github.io/Portafolio-v2/v4/ junto con el resto del sitio.
La rama `preview` es la única que despliega.

## Desarrollo local

```bash
npm install
npm run build
npx serve dist
```
