# Portafolio v2

Portfolio template built with Next.js. All texts are lorem ipsum and all images are placeholders — replace them with real content.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Preview deployment

The `preview` branch is the only branch that automatically builds and deploys this site to GitHub Pages. Push commits to `preview` to update the public preview. `main` is retained as a reference and does not trigger deployments.
